# Character Sheet Edit Mode

The Character Sheet features an interactive **Edit Mode** that allows you to customize your hero's abilities, skills, and classes.

## Enabling Edit Mode

To enter Edit Mode, click the **Edit Stats** button located at the top-right of your character sheet.

When Edit Mode is active:
- The button will turn secondary (darker).
- Interactive controls will appear across the sheet.
- A "Syncing..." indicator will appear when changes are being saved to the ashes.

## Managing Skills

In the **Skills** tab, you will see radio buttons next to each skill. These allow you to set your proficiency level:

- **Empty Circle:** No proficiency.
- **Darker Ember Circle:** Proficient (Add your Proficiency Bonus).
- **Bright Flare Circle with Glow:** Expertise (Add double your Proficiency Bonus).

Changes to skills are saved immediately as you toggle them.

## Adjusting Ability Scores

In the sidebar, you can adjust your core ability scores (Strength, Dexterity, etc.) by typing in the input boxes. You can also toggle **Saving Throw Proficiency** by clicking the checkbox next to each ability.

## Class Management

In the character header, while Edit Mode is active, you can:
- **Adjust Levels:** Change the number next to a class name to update your level.
- **Add Classes:** Use the "+ Add Class" dropdown to multiclass.
- **Remove Classes:** Click the small `×` next to a class to remove it.

## Finishing Edits

Once you are done customizing your hero, click the **Finish** button to exit Edit Mode and lock your stats. All changes are persistently stored in the Scorimundi archives.
